## 音色从哪来

全部来自 [k2-fsa/sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) 官方 Release
的 `tts-models` 标签。`id` 就是那个 tarball 的名字（不含 `.tar.bz2`）。

主程序不分发任何语音模型 —— 这里只有下载地址。下载后模型存在你手机上，
完全离线推理。

## 想加自己的音色？

`voices.json` 里加一条就行：

```json
{
  "id": "你的音色 id",
  "label": "显示名",
  "description": "一句话说明",
  "badge": "轻量",
  "sizeBytes": 14016124,
  "sampleText": "试听用的一句话"
}
```

- `id` 缺省按下拼官方地址；想用自己的压缩包就填 `url`
- `sizeBytes` 不确定就填 `0`（跳过大小校验）
- 压缩包里的布局要能被认出来：主程序是**扫目录找最大的 `.onnx`**，
  再在同级找 `tokens.txt` / `lexicon.txt` / `*.fst`。所以只要那是个
  sherpa-onnx 的 VITS 包，目录叫什么都能用

改完把**文件**（不是文件夹）重新压成 zip，再导入。

## 前置条件

神经语音需要一个原生推理库（onnxruntime，约 36 MB）。它**不在安装包里** ——
第一次下载音色时会自动拉取。不下载音色的人不用付这 36 MB。
