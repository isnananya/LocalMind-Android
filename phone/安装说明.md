# LocalMind 手机版安装包 · 2026-10-15

## 能不能装在手机上？

**能。** 这个 APK 里的原生库是给**手机 CPU 架构**编的，不是模拟器的：

| 架构 | 用在哪 | 这个包里 |
| --- | --- | --- |
| `arm64-v8a` | **2017 年以后的手机基本都是它** | ✅ 有 |
| `armeabi-v7a` | 老的 32 位手机（约 2016 年前） | ✅ 有 |
| `x86_64` | 模拟器 / Intel 平板 | ❌ 没有（模拟器用另一个包） |

确认方法（可选）：设置 → 关于手机 → 处理器，写着 **64 位 / arm64 / ARMv8** 就能装。

最低系统要求：**Android 8.0（API 26）**。

## 装什么

| 文件 | 必装？ | 说明 |
| --- | --- | --- |
| `LocalMind-1.0.0-手机版.apk` | ✅ | 主程序 **14.4 MB** |
| `官方模型库插件.zip` | ✅ | **52 个模型 + 17 个音色**，11.7 KB |
| `本地生图后端插件.zip` | 想生图才装 | 14.4 MB |
| `中文表情包插件.zip` | 可选 | 让 AI 发 emoji，3.7 KB |
| `图片表情包插件.zip` | 可选 | 让 AI 发图片梗图，7 KB |
| `暖橙界面主题插件.zip` | 可选 | 不装也有 4 套内置主题 |
| `语音音色插件.zip` | 一般不用 | 模型库插件已含 17 个音色，装这个会重复 |

插件装法：应用里「**我的 → 插件 → 导入插件 zip**」。

## 装完先做两件事

**1. 下载一个对话模型**（「模型」页，走国内 hf-mirror 镜像）

| 想干什么 | 下哪个 | 体积 |
| --- | --- | --- |
| 先跑通 | ERNIE 4.5 0.3B | 229 MB |
| **日常默认** | Qwen3.5 2B | 1.2 GB |
| 质量优先 | Qwen3.5 4B | 2.6 GB |
| 看图（也能纯文字聊天） | Qwen3.5 2B（看图） | 1.2 GB |
| 决策 / 判断 | Gutsy 0.8B | 505 MB |

**2. 想用语音的话**：先到「我的 → 语音与音色」下载「**语音引擎**」，再下音色。
模型页「语音」分类点下载时会先检查引擎在不在，不在会直接提示，不会白下 100 MB。

## 手机上会有差异的地方（提前说清，免得当成 bug）

1. **手机比模拟器快很多。** 模拟器是在翻译层上跑，同一个模型手机上通常快 2–5 倍。
2. **生图需要先装生图后端插件**，而且那份必须是 arm64 版。装完若提示「不支持当前设备」，就是还没有 arm64 版；其余功能不受影响。
3. **耗电与发热**：跑大模型时手机必热，这是硬件决定的。建议插着电用。
   线程数默认只用 4 个大核（矩阵乘是内存带宽瓶颈，摊到小核上反而更慢）。
4. **后台被杀**：Android 内存紧张时会杀进程。想让它常驻（比如当本机 API 用），
   到「我的 → 本机 API 服务」打开，它会起一个前台服务。

## 这个包里没有的东西

* **模型权重**（几十 GB，装完在应用里下）
* **模拟器用的 x86_64 版**（在 `release/` 目录里）

完整模型清单见仓库 `docs/PLUGINS.md`；插件开发文档在应用里「我的 → 插件 → 开发文档」。
