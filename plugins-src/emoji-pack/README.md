# 中文表情包 · LocalMind 插件

让 AI 在回复里发表情包。

## 装法

1. 打开 LocalMind →「我的」→「插件」
2. 点「从文件导入 zip」，选这个 zip
3. 装完自动启用。到「我的 → 插件」里能看到它

装好之后，AI 回复里会出现表情。**不需要给模型额外下任何模型** ——
表情是系统 emoji，直接渲染。

## 里面有什么

| 文件 | 作用 |
| --- | --- |
| `plugin.json` | 插件清单，声明「我提供表情包能力」 |
| `emoji.json` | 30 个表情 + 16 个情感标签 + 45 条关键词 |

## 想改成自己的？

`emoji.json` 是纯 JSON，用任何文本编辑器都能改。最简单的方式：

1. 把这个 zip 解开（或用 7-Zip 打开）
2. 编辑 `emoji.json`
3. 把里面的文件重新压成 zip（**注意：`plugin.json` 和 `emoji.json` 必须在 zip 根目录，不能套一层文件夹**）
4. 重新导入

一个表情长这样：

```json
{ "char": "😄", "emotion": "开心", "description": "开心的大笑",
  "aliases": ["高兴", "快乐"], "weight": 3 }
```

- `char`：要发出去的 emoji 字符，可以是多个（`"😂🤣"` 会一次发俩）
- `emotion`：情感标签。**模型就是按这个标签点菜的**，所以标签要好记
- `description`：更细的场景，模型写这个也能命中
- `aliases`：同义词
- `weight`：同标签下有多个表情时，数字大的更容易被选中

`keywords` 那张表是兜底：模型不写标签、而是写「哈哈」的时候，也能映射到「开心」。

## 授权

- **数据格式与匹配算法**：本项目原创，MIT。
- **emoji 字符**：Unicode 标准字符，由你手机的系统字体渲染。
  本插件**不分发任何字体或图片素材**，所以没有第三方素材的授权问题。

这也是这个功能用 emoji 而不是图片包的原因：图片表情包几乎都带着来源不明的版权，
而 emoji 是系统的一部分。

## 设计参考

「情感标签 + 描述匹配 + 结果缓存」这个思路参考了
[RiyaBot](https://github.com/hsd221/riyabot) 的 `emoji_api`（GPL-3.0）。

本项目**没有使用它的任何代码或数据**，实现完全独立；也正因为它是 GPL，
这个功能才被做成插件而不是内置 —— 授权边界和代码边界重合。
